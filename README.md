# velib-data-pipeline
# Pipeline data : disponibilité des stations Vélib' à Paris
Objectif : comprendre quand et où les stations Vélib' manquent de vélos.
Source : API open data de la Ville de Paris, mise à jour toutes les minutes.
Stack prévue : Python, PostgreSQL, dbt, Airflow, Power BI.
Statut : en construction (projet de 30 jours).
